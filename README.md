# ⛳ 원온 미니골프 (ONEOINE MINI GOLF)

원온 홍보·이벤트용 **3D 클럽하우스 + 3홀 미니골프 웹앱 MVP**입니다.
회원 연동 없이 닉네임과 캐릭터 색상만 고르면 **3D 대기실(클럽하우스 광장)** 에 들어가고,
광장에서 사람들을 만나 **이모지로 인사**한 뒤 빛나는 **플레이룸 게이트**로 들어가면 3홀 라운드가 시작됩니다.
홀인원·버디 같은 이벤트를 달성하면 (다음 단계에서) 원온 앱에 등록할 수 있는 쿠폰 번호를 지급하는 구조를 염두에 두고 만들었습니다.

> 현재 버전은 **쿠폰 기능 제외** 상태입니다. 대기실·이모지 소통·플레이룸(3홀)·기록·공유·탭 간 실시간 동기화까지 구현했습니다.

- 스택: **Vite + TypeScript + Three.js + cannon-es**
- 외부 서버/API 키/오디오 파일 의존 없음 (효과음은 Web Audio로 실시간 합성)

## 2. 입장 흐름과 조작법

```
랜딩(닉네임·색상) → 3D 대기실(클럽하우스 광장) → 🌀 플레이룸 게이트 → 3홀 미니골프 → 스코어카드 → 🏠 대기실
```

### 2-1. 대기실 (클럽하우스 광장)

밝은 잔디 광장에 연못·나무·벤치·클럽하우스 건물·가로등이 있고, 광장 끝에 **빛나는 플레이룸 게이트**가 있습니다.
채팅은 없고 **이모지(👋⛳🔥👏😂🎉)** 로만 감정을 주고받습니다.

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | `WASD` / `방향키` | 화면을 **드래그**(조이스틱) |
| 이동(포인트) | 바닥 **클릭** → 그쪽으로 걸어감 | 바닥 **탭** → 그쪽으로 걸어감 |
| 이모지 | 하단 이모지 바 클릭 (머리 위 말풍선 + 효과음) | 동일 |
| 플레이룸 입장 | 게이트로 걸어 들어가기 또는 `플레이룸 입장 ⛳` 버튼 | 동일 |
| 소리 / 도움말 | 우상단 🔊 / `?` | 동일 |

- 혼자 접속해도 **로비 게스트 4명**(버디헌터·핑크공·싱커·캐디)이 광장을 거닐며 가끔 이모지로 반응합니다.
- 내가 이모지를 보내면 근처 게스트가 잠시 뒤 같은/비슷한 이모지로 화답합니다.
- 같은 브라우저의 다른 탭에서 접속한 사람은 **위치·방향·이모지·플레이룸 이동**이 실시간으로 보입니다.

### 2-2. 플레이룸 (3홀 미니골프)

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 조준 | `A`/`D`, `←`/`→` 또는 화면 **좌우 드래그** | 화면 좌우 **드래그**, ◀ ▶ 버튼 |
| 뷰 전환 | `V` 또는 우상단 **🔭 뷰 전환** | 우상단 **🔭** 버튼 |
| 스윙(파워) | **스페이스바**·`Enter`를 **꾹 누르고 있다 떼기** 또는 `스윙!` 버튼/게이지 **꾹 눌렀다 떼기** | `스윙!` 버튼/게이지 **꾹 눌렀다 떼기** |
| 스윙(정확도) | 임팩트 존에서 **한 번 탭**(화면 아무 곳·`스페이스바`) | 임팩트 존에서 **한 번 탭** |
| 클럽 바꾸기 | 하단 클럽 칩 (1W·3W·5I·7I·9I·PW·SW·PT) | 동일 |
| 카메라 자유 시점 | 마우스 **오른쪽 버튼 드래그** | **두 손가락 드래그** |
| 공 되돌리기 | `R` (+1벌타) | — |
| 소리 켜기/끄기 | `M` 또는 우상단 🔊 | 우상단 🔊 |
| 플레이 가이드 / 도움말 | `H` 또는 우상단 `?` | 우상단 `?` |

- **첫 입장 가이드**: 플레이룸에 처음 들어가면 ① 조준·뷰 전환 ② 추천 클럽 ③ 꾹 눌러 파워·타이밍 탭을 3장으로 보여줍니다.
  한 번 보면 다시 뜨지 않고, 우상단 `?` 버튼으로 언제든 다시 볼 수 있어요.
- **스윙(홀드 & 릴리즈)**: `스윙!` 버튼이나 게이지를 **꾹 누르고 있는 동안** 파워 게이지가 0% → 100%로 차오르고,
  100%에 닿으면 다시 0% 쪽으로 내려가며 왕복합니다. **손을 떼는 순간(pointerup)의 게이지 위치가 파워로 확정**되고,
  이어서 게이지가 왼쪽 **임팩트 존**으로 돌아올 때 **한 번 탭**하면 정확도가 정해지며 샷이 나갑니다.
  존 한가운데를 맞추면 Perfect, 살짝 어긋나면 Good(훅/슬라이스), 크게 어긋나면 Miss예요.
  너무 짧게 눌렀다 뗀 실수 탭은 스윙이 되지 않고 준비 상태로 돌아갑니다. (`MIN_HOLD_SECONDS`)
- **뷰 전환**: `백뷰`(공 뒤) → `타겟뷰`(착지 예정 지점·그린 상공) → `탑뷰`(코스 전체)를 돌려 봅니다.
  타겟뷰에서는 착지 링과 그린·벙커·연못이 한눈에 들어와 파워를 가늠하기 좋습니다.
- **거리 표시**: HUD에 핀까지 **남은 거리**와 선택 클럽의 **최대 비거리(100%)**가 표시되고,
  누르고 있는 동안 **현재 파워 % · 예상 비거리**(예: `68% · 34.0m`)가 실시간으로 나옵니다.
  게이지 바에는 핀까지 필요한 파워 위치에 **🎯 목표 마커**가 찍힙니다.
- **에임 가이드**: 조준하는 동안 공 앞으로 점선 궤적·착지 링·정지 지점 링이 표시됩니다.
- **샷 후**: 골퍼는 샷을 친 자리에 그대로 서서 **공만 날아가는 걸** 지켜보고,
  공이 멈추면 새 공 옆으로 걸어가 어드레스 자세를 잡습니다.

## 4. 여러 탭에서 함께 (실시간 동기화)

이 MVP는 서버 없이 **BroadcastChannel** 로 같은 브라우저의 탭끼리 통신합니다.

1. 브라우저 탭을 2개 이상 엽니다. (같은 주소)
2. 각 탭에서 닉네임/캐릭터 색상을 다르게 정하고 **대기실 입장**을 누릅니다.
3. 대기실에서 서로의 **캐릭터 + 닉네임**이 보이고, 걷는 위치·이모지 말풍선이 실시간으로 동기화됩니다.
4. 한쪽이 플레이룸 게이트로 들어가면 다른 탭에서는 그 사람이 **⛳ 플레이룸**으로 표시되고, 플레이룸 안에서는 서로의 **반투명 공 + 닉네임 라벨**과 샷·홀인·이모지가 동기화됩니다. (같은 홀에 있는 플레이어만 코스에 렌더링)
5. 스코어카드의 `🏠 대기실로 돌아가기`로 대기실에 복귀하면 다시 광장에서 만납니다.

> 시크릿 창은 BroadcastChannel이 분리되어 서로 보이지 않습니다. 일반 탭 2개로 테스트하세요.

### 실제 서버로 교체하는 지점

`src/net/realtime.ts` 의 `Realtime` 인터페이스(`send` / `onMessage` / `close`)만 구현하면 전송 계층을 갈아 끼울 수 있습니다.
메시지는 모두 순수 JSON(`NetMessage`)입니다.

```ts
// 예: Supabase Realtime 어댑터로 교체
export function createRealtime(room: string): Realtime { /* ... */ }
```

| 후보 | 특징 |
| --- | --- |
| Supabase Realtime (Broadcast) | 무료 티어로 시작하기 쉽고, 추후 Auth/DB(쿠폰 발급)까지 한 곳에서 |
| Cloudflare Durable Objects + WebSocket | 방(room) 단위 상태를 서버가 들고 있어 순서/충돌 제어에 유리 |
| PartyKit / Ably / Firebase RTDB | 위 인터페이스로 감싸면 동일하게 사용 가능 |

서버로 옮길 때 추가로 필요한 것: 방 코드 입장, 발신자 인증(닉네임 위조 방지), 레이트 리밋,
그리고 **쿠폰 번호 발급은 반드시 서버에서 검증 후 발급**.

## 5. 쿠폰 기능을 붙일 때 (다음 단계 메모)

이번 범위에서는 제외했지만, 구조상 아래 지점에 붙이면 됩니다.

1. **이벤트 트리거 정의** — `Game`의 `onHoled(holeIndex, strokes, label)` / `onFinish(result)` 콜백이 이미 있습니다.
   예: `홀인원 1회 이상`, `3홀 합계 Par 이하`, `전체 9타 이하` 등.
2. **보상 요청** — `src/net/realtime.ts` 에 `"claim"` 메시지를 추가하고 서버(Edge Function 등)에서 검증 후
   원온 앱에서 등록 가능한 쿠폰 코드를 발급·응답.
3. **표시** — 스코어카드 하단에 쿠폰 번호 + 복사 버튼 추가 (`resultToText` 와 같은 방식).
4. **중복 방지** — 브라우저 로컬 저장(`localStorage`)은 우회 가능하므로 쿠폰은 서버 측 1회 발급 + 사용 이력 관리.

## 7. 조작감 튜닝 포인트

`src/game/constants.ts`

| 상수 | 의미 |
| --- | --- |
| `GAUGE_POWER_SECONDS` / `GAUGE_IMPACT_SECONDS` | 게이지가 0→100%로 차오르는 시간(이후 같은 시간으로 왕복) / 임팩트 존으로 돌아오는 시간 |
| `MIN_HOLD_SECONDS` / `MIN_POWER` | 이보다 짧게 떼면 실수 탭으로 취소 / 떼는 순간 확정되는 최소 파워 |
| `MIN_POWER_RATIO` | 0% 파워에서도 나가는 속도 비율 |
| `CUP_RADIUS` / `CUP_ATTRACT_RADIUS` | 컵 판정 반경 / 빨려 들어가는 반경 |
| `STROKE_LIMIT_EXTRA` | 홀당 최대 타수 = Par + 값 |

클럽별 비거리·탄도는 `src/game/clubs.ts` 의 `loft`·`speed`(풀파워 발사 속도)로 정해지고,
파워→비거리 환산 지수(`DISTANCE_EXPONENT`)가 HUD 예상 비거리와 🎯 목표 마커에 쓰입니다.
클럽을 고친 뒤에는 `npm run verify:physics` 로 캐리/총비거리 실측을 다시 확인하세요.

`src/game/physics.ts` 의 `linearDamping`(공 감쇠)과 잔디 마찰로 굴러가는 거리가 정해집니다.
